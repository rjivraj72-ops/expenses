# Fonts

`fraunces-latin-800-normal.woff2` is **Fraunces** (ExtraBold, Latin), used for the wordmark, headings and big balances. It's from the Fraunces Project (Undercase Type) and licensed under the SIL Open Font License 1.1, which allows bundling it in this app: https://openfontlicense.org

All other text uses the device's system font (San Francisco on iPhone and Mac).
